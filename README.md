# My To-Do App

A simple responsive To-Do List web application built with HTML, CSS and JavaScript.

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Saves tasks in browser localStorage
- Responsive design

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository named `todo-app`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's Settings.
4. Go to Pages.
5. Under Build and deployment, select `Deploy from a branch`.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish.
8. Your live URL will be shown in the Pages section.
